# techplanner-recommendation-lib

Librería desarrollada en lenguaje C que genera recomendaciones de componentes de computador según el tipo de uso y el presupuesto.

## Tipos de uso soportados

- Gaming
- Oficina
- Diseño
- Servidores
- Presupuesto

## Estructura

- `src/main/c`: implementación de la librería
- `src/main/include`: headers públicos
- `src/test/c`: pruebas y programa de validación
- `Makefile`: compilación local

## Compilación

make

## Ejecución

./target/recommendation-lib.exe
